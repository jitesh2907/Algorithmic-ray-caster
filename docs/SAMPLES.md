## 4. Help & Controls Manual Screen

```
================================================================================
                  ALGORITHMIC RAY CASTER - HELP & MANUAL                        
================================================================================
 1. NAVIGATION CONTROLS:
    - W : Move forward along viewing angle by 0.25 units
    - S : Move backward along viewing angle by 0.25 units
    - A : Rotate camera left by 10.0 degrees
    - D : Rotate camera right by 10.0 degrees
    - Q : Strafe left perpendicular to viewing angle
    - E : Strafe right perpendicular to viewing angle
    - Tip: You can chain commands! Entering 'wwad' moves forward twice,
           turns left, and turns right in one execution.

 2. DISPLAY & ENVIRONMENT SETTINGS:
    - M : Toggle Top-Down Mini-Map on / off
    - P : Cycle ASCII Shading palette (Unicode Blocks / Classic ASCII / Contrast)
    - 1 : Switch to Map Preset 1 (10x8 Classic Maze)
    - 2 : Switch to Map Preset 2 (10x8 Pillar Hall)
    - 3 : Switch to Map Preset 3 (12x10 Winding Labyrinth)
    - H : Show this help manual
    - X / QUIT : Exit the application

 3. HOW THE RAY CASTER WORKS:
    - Digital Differential Analyzer (DDA) traverses the 2D grid cell-by-cell.
    - Calculates perpendicular distance to avoid fish-eye lens curvature.
    - Apparent wall height = ScreenHeight / PerpendicularDistance.
    - Characters are shaded based on depth and surface orientation (X vs Y hits).
    - Player has an active collision radius preventing wall clipping.
================================================================================
 Press [Enter] to return to the simulation...
```
